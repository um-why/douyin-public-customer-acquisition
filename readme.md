# Skill Name: 公域流量精准获客与竞品截流系统

## Description

**抖音公域流量精准获客系统** 是一款专为增长黑客、销售团队和市场营销人员设计的自动化工具。它不再局限于简单的数据抓取，而是深入抖音评论区，通过关键词筛选、竞品监控和舆情分析，帮你挖掘出带有“求带”、“怎么买”、“求推荐”等高意向的潜在客户线索。

## 适用场景

| 场景           | 解决方案                   | 预期效果                     |
| :------------- | :------------------------- | :--------------------------- |
| **低成本获客** | 关键词搜索 + 评论区筛选    | 快速定位有明确需求的公域用户 |
| **竞品转化**   | 监控竞品爆款视频评论区     | 将竞品的粉丝转化为你的客户   |
| **话术优化**   | 分析用户真实痛点和提问     | 优化销售话术，直击用户痛点   |
| **热点借势**   | 实时获取热榜，结合热点获客 | 快速获取平台自然流量         |
